# ⭐ S3 Object Lambda

**S3 Object Lambda** lets you run a **Lambda function** to transform data **on the fly** when an object is requested from Amazon S3—**without modifying the original object** stored in the bucket.

When a client performs **`GetObject`**, **`HeadObject`**, or **`ListObjects`** through a **special Object Lambda Access Point**, S3 invokes your Lambda function to process the request.

The Lambda function:

* Accesses the original object using a **pre-signed URL**
* Applies transformation logic
* Returns the transformed data to the requester using **`WriteGetObjectResponse`**

This approach **avoids creating unnecessary copies** of objects in S3.

---

## 🔁 High-Level Request Flow

```
Client
  ↓
S3 Object Lambda Access Point
  ↓
S3 invokes Lambda (event includes getObjectContext)
  ↓
Lambda fetches original object using inputS3Url
  ↓
Lambda transforms the object
  ↓
Lambda calls WriteGetObjectResponse
  ↓
Client receives transformed bytes
```

---

## 🧩 Key Concepts

* **Object Lambda Access Point**
  Acts as the entry point for requests that require transformation.

* **`inputS3Url`**
  A pre-signed URL provided to the Lambda function to fetch the original object.

* **`WriteGetObjectResponse`**
  Core API used by Lambda to send transformed data back to the original requester.

 below is lambda function code:
 ```python
# transform.py
import boto3
import requests
from botocore.config import Config

# This function capitalizes all text in the original object
def lambda_handler(event, context):
    # event contains getObjectContext when configured for GetObject
    object_context = event["getObjectContext"]

    # presigned URL to fetch original object (supporting access point)
    s3_url = object_context["inputS3Url"]

    # route + token used when returning the transformed object
    request_route = object_context["outputRoute"]
    request_token = object_context["outputToken"]

    # fetch original object via presigned URL (no extra S3 read IAM needed)
    response = requests.get(s3_url)
    response.raise_for_status()

    original_object = response.content.decode("utf-8")

    # transform: uppercase (replace with your logic)
    transformed_object = original_object.upper()

    # write transformed result back to S3 Object Lambda to return to caller
    s3 = boto3.client('s3', config=Config(signature_version='s3v4'))
    s3.write_get_object_response(
        Body=transformed_object,
        RequestRoute=request_route,
        RequestToken=request_token
    )

    # end — return status
    return {'status_code': 200}
```

## **S3 URI vs ARN (Summary Notes)**

### **1) S3 URI format**

* Starts with: `s3://`
* Example:
  `s3://my-bucket/path/to/file.txt`
  `s3://arn:aws:s3:us-east-1:123456789012:accesspoint/my-ap`
* **Used for:** UI, Athena, Spark, EMR, Hadoop
* **Purpose:** Human-readable way to point to an S3 location
* **Not used by:** AWS CLI bucket parameter

👉 Think of it as a **friendly location format**

---

### **2) ARN (Amazon Resource Name) format**

* Starts with: `arn:aws:`
* Example:
  `arn:aws:s3:us-east-1:123456789012:accesspoint/my-ap`
* **Used for:**

  * AWS CLI
  * IAM policies
  * boto3 / APIs
  * S3 Access Points & Object Lambda
* **Purpose:** Official AWS resource identifier

👉 Think of it as the **machine-friendly ID**

---

### **🔥 Most Important Difference**

* **AWS CLI expects the ARN, NOT `s3://`**
* Using `s3://` with Access Points in CLI ❌ fails
* Using ARN ✔ works

---

### **Why AWS shows both**

| Format | Used for             | Meaning              |
| ------ | -------------------- | -------------------- |
| S3 URI | UI & analytics tools | Just a location      |
| ARN    | CLI, IAM, APIs       | Official resource ID |

---

### **Simple Analogy**

* **S3 URI** = Home address
* **ARN** = Government ID

Humans use addresses, systems use IDs.

---

### **Key Rule**

✔ **Always use ARN for Access Points & Object Lambda in CLI/API calls**

---

### **Final One-Line Summary**

* `s3://` → human-readable path
* `arn:aws:` → required for AWS APIs and CLI

Only **ARN** works for Access Points and Object Lambda.

# 🔥 Personalized Document (Auth-based)

The demo behavior:

S3 stores a template file (e.g., offer.txt) containing placeholders like `{{name}}` and `{{id}}`.
Client calls API Gateway endpoint with Authorization: Bearer <JWT>.
Lambda verifies the JWT (HS256) using a secret stored in an environment variable, extracts user claims (e.g., name, user_id), fetches the S3 object, substitutes placeholders, and returns the personalized content

Requirements:
Bucket,object key,lambda name, API GATEWAY (HTTP API),env var in lambda (jwt_secret),set this to str like `supersecret123`

example of offer.text file is:
```
Hello {{name}},
We are excited to offer you access to our new data platform. Your user id is {{user_id}}.

Regards,
Team Data Eng
```

## LAMBDA CODE

```python
# lambda_function.py
import os
import json
import boto3
import base64
import hmac
import hashlib
import re
from urllib.parse import parse_qs

s3 = boto3.client("s3")

# Helper: base64url decode (handles padding)
def b64url_decode(input_str: str) -> bytes:
    rem = len(input_str) % 4
    if rem:
        input_str += "=" * (4 - rem)
    return base64.urlsafe_b64decode(input_str.encode('utf-8'))

# Verify HS256 JWT without external libs
def verify_jwt(token: str, secret: str):
    try:
        header_b64, payload_b64, sig_b64 = token.split(".")
    except ValueError:
        raise ValueError("Invalid JWT format")

    signing_input = f"{header_b64}.{payload_b64}".encode("utf-8")
    signature = b64url_decode(sig_b64)

    expected = hmac.new(secret.encode("utf-8"), signing_input, hashlib.sha256).digest()
    if not hmac.compare_digest(expected, signature):
        raise ValueError("Invalid JWT signature")

    payload_json = b64url_decode(payload_b64).decode("utf-8")
    payload = json.loads(payload_json)
    # optional: check exp
    if "exp" in payload:
        import time
        if time.time() > payload["exp"]:
            raise ValueError("JWT expired")
    return payload

# Simple placeholder replace for {{name}} style tokens
PLACEHOLDER_RE = re.compile(r"\{\{\s*([a-zA-Z0-9_]+)\s*\}\}")

def render_template(template_text: str, context: dict) -> str:
    def repl(m):
        key = m.group(1)
        return str(context.get(key, m.group(0)))
    return PLACEHOLDER_RE.sub(repl, template_text)

def lambda_handler(event, context):
    # --- 1) Extract Authorization header ---
    headers = event.get("headers") or {}
    auth = headers.get("authorization") or headers.get("Authorization")
    if not auth or not auth.lower().startswith("bearer "):
        return {"statusCode": 401, "body": "Missing or invalid Authorization header"}

    token = auth.split()[1]
    secret = os.environ.get("JWT_SECRET")
    if not secret:
        return {"statusCode": 500, "body": "Server misconfigured: no JWT secret"}

    # Verify token and get claims
    try:
        claims = verify_jwt(token, secret)
    except Exception as e:
        return {"statusCode": 401, "body": f"JWT verification failed: {str(e)}"}

    # --- 2) Get query param 'key' for S3 object (default tutorial template) ---
    # If using API Gateway HTTP API, event["queryStringParameters"] is provided. But some forms of integration pass raw query.
    key = None
    if event.get("queryStringParameters"):
        key = event["queryStringParameters"].get("key")
    else:
        # fallback: parse rawQueryString
        raw_qs = event.get("rawQueryString", "")
        qs = parse_qs(raw_qs)
        key = qs.get("key", [None])[0]

    if not key:
        key = "offer.txt"

    bucket = os.environ.get("BUCKET_NAME") or "your-demo-bucket"

    # --- 3) Fetch object from S3 ---
    try:
        obj = s3.get_object(Bucket=bucket, Key=key)
        body = obj["Body"].read()
        # try decode as utf-8; binary content will fail
        try:
            text = body.decode("utf-8")
        except:
            return {"statusCode": 400, "body": "Object is not a text file"}
    except Exception as e:
        return {"statusCode": 404, "body": f"S3 get_object error: {str(e)}"}

    # --- 4) Personalize using claims ---
    # You may want to map claim names to placeholder names, e.g., claims['sub'] -> user_id
    # Example: allow both name and user_id
    context = {}
    # copy all claims into context (stringify simple values)
    for k, v in claims.items():
        # avoid nested structures
        if isinstance(v, (str, int, float, bool)):
            context[k] = v

    personalized = render_template(text, context)

    # --- 5) Return personalized content with headers ---
    return {
        "statusCode": 200,
        "headers": {
            "Content-Type": "text/plain"
        },
        "body": personalized
    }
```
