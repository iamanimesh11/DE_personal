# ⭐ S3 Object Lambda

its basically let run lambda function and perform transofrm logic on requested object on fly and return it to use without modifying actual object stored.
when someone does **Getobject headobject listobject** via special access point .
function can access the original object using pre-signed URL,transform it and send transformed bytes back to original caller using **WriteGetObjectResponse**. this prevents creating unnceassary copies of object \

How the request flow works (high level): client → S3 Object Lambda Access Point → S3 Object Lambda invokes your Lambda (event includes getObjectContext) → your Lambda fetches the original object using inputS3Url → transform → call WriteGetObjectResponse to return result → client receives transformed bytes.
