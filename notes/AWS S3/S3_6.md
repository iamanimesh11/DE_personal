# ⭐ S3 Object Lambda

its basically let run lambda function and perform transofrm logic on requested object on fly and return it to use without modifying actual object stored.
when someone does **Getobject headobject listobject** via special access point .
function can access the original object using pre-signed URL,transform it and send transformed bytes back to original caller using **WriteGetObjectResponse**. this prevents creating unnceassary copies of object \

How the request flow works (high level): client → S3 Object Lambda Access Point → S3 Object Lambda invokes your Lambda (event includes **getObjectContext**) → your Lambda fetches the original object using inputS3Url → transform → call **WriteGetObjectResponse** to return result → client receives transformed bytes. 

Prereqs
AWS account + permissions to create S3, Lambda, IAM roles and Access Points (or an IAM user with AmazonS3FullAccess, AWSLambda_FullAccess, IAMFullAccess for the tutorial).

❓ steps to perform:
step 1 :s3 bucket created and file uploaded to it 
step 2: need to create access point in s3,data source will be this bucket . This will be the supporting access point used by Object Lambda. 
step 3 : now to create lambda func that transform object.lambda use **inputs3url** presigned url  to get source object and **write_get_object_response** to send transformed bytes back
 That write_get_object_response behavior is the core API for Object Lambda responses

 below is lambda function code:
 ```python
# transform.py
import boto3
import requests
from botocore.config import Config

# This function capitalizes all text in the original object
def lambda_handler(event, context):
    # event contains getObjectContext when configured for GetObject
    object_context = event["getObjectContext"]

    # presigned URL to fetch original object (supporting access point)
    s3_url = object_context["inputS3Url"]

    # route + token used when returning the transformed object
    request_route = object_context["outputRoute"]
    request_token = object_context["outputToken"]

    # fetch original object via presigned URL (no extra S3 read IAM needed)
    response = requests.get(s3_url)
    response.raise_for_status()

    original_object = response.content.decode("utf-8")

    # transform: uppercase (replace with your logic)
    transformed_object = original_object.upper()

    # write transformed result back to S3 Object Lambda to return to caller
    s3 = boto3.client('s3', config=Config(signature_version='s3v4'))
    s3.write_get_object_response(
        Body=transformed_object,
        RequestRoute=request_route,
        RequestToken=request_token
    )

    # end — return status
    return {'status_code': 200}
```
