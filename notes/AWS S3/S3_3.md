 4️⃣ Advanced Bucket Policy Conditions
These are important and appear in exams.

✔ Block by IP
```json
"Condition": {
  "IpAddress": { "aws:SourceIp": "192.168.1.0/24" }
}
```
means: only allow request from spcific IP range ,like allow access from corporate network

✔ Allow only specific prefix
"Condition": {
  "StringLike": {
    "s3:prefix": "raw/*"
  }
}

✔ Enforce HTTPS
```json
"Condition": {
  "Bool": { "aws:SecureTransport": "false" }
}
```
meaning : deny all htto and allow only https, it ensure data is accessed securely

✔ Enforce encryption (AWS exam loves this!)
```json
"Condition": {
  "StringEquals": {
    "s3:x-amz-server-side-encryption": "AES256"
  }
}
Or for KMS:

"Condition": {
  "StringEquals": {
    "s3:x-amz-server-side-encryption": "aws:kms"
  }
}
```
means user must use sse-kms ,and reject unencrypted uploads ,sse-s3 uploads 
example:ensure all uploaded objects are encryptd with kms
These guarantee ALL uploads are encrypted.
