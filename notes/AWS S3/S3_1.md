<h2> Amazon S3 = Object Storage Service</h2>

It stores data as objects (not files or blocks).

Each object has:

- **Data** — the actual file  
- **Metadata** — file type, size, etc.  
- **Key** — unique name in the bucket  

### Example

s3://my-company-logs/2025/october/app_logs.json

- **Bucket**: `my-company-logs`  
- **Key (path)**: `2025/october/app_logs.json`

🧱 . How Object Storage Differs from Block/File Storage

| Type                    | Description                                         | Common Use                           |
| ----------------------- | --------------------------------------------------- | ------------------------------------ |
| **Block Storage**       | Splits data into fixed-size blocks (e.g., EBS).     | Databases, OS volumes                |
| **File Storage**        | Hierarchical (folders/files), supports locking.     | Shared drives (EFS, NAS)             |
| **Object Storage (S3)** | Flat structure, identified by key, highly scalable. | Backups, data lakes, logs, analytics |

💡 Think of S3 as a global file cabinet — infinite drawers, each storing an object with a label (key).

When you upload an object:
It’s automatically replicated across multiple Availability Zones (AZs) within the region.
