<h2> Amazon S3 =  Simple  Storage Service</h2>

It stores data as objects (not files or blocks).

Each object has:

- **Data** — the actual file  
- **Metadata** — file type, size, etc.  
- **Key** — unique name in the bucket  

### Example

s3://my-company-logs/2025/october/app_logs.json

- **Bucket**: `my-company-logs`  
- **Key (path)**: `2025/october/app_logs.json`

🧱 . How Object Storage Differs from Block/File Storage

| Type                    | Description                                         | Common Use                           |
| ----------------------- | --------------------------------------------------- | ------------------------------------ |
| **Block Storage**       | Splits data into fixed-size blocks (e.g., EBS).     | Databases, OS volumes                |
| **File Storage**        | Hierarchical (folders/files), supports locking.     | Shared drives (EFS, NAS)             |
| **Object Storage (S3)** | Flat structure, identified by key, highly scalable. | Backups, data lakes, logs, analytics |

💡 Think of S3 as a global file cabinet — infinite drawers, each storing an object with a label (key).

When you upload an object:
It’s automatically replicated across multiple Availability Zones (AZs) within the region.

# versioning ,lifecycle rules and storage classes:

versioning is simple to keep multipl versions of file in bucket 

lifecycle rules :automatic  archiving or deletion ,example
aws s3api put-bucket-lifecycle-configuration --bucket my-de-lake-animesh11 --lifecycle-configuration '
```json
{
  "Rules": [
    {
      "ID": "MoveOldRawToGlacier",
      "Status": "Enabled",
      "Prefix": "raw/",
      "Transitions": [
        {
          "Days": 30,
          "StorageClass": "GLACIER"
        }
      ],
      "Expiration": {
        "Days": 365
      }
    }
  ]
}'
```

it makes file raw/ move to glacier after 30 days (cheap cold storage) and delete file after 1 year
command to verify:
aws s3api get-bucket-lifecycle-configuration --bucket my-de-lake-animesh11

```
import boto3
import csv
import io
import json
from datetime import datetime

s3 = boto3.client('s3')

def lambda_handler(event, context):
    # Extract bucket and file info from event
    record = event['Records'][0]
    bucket_name = record['s3']['bucket']['name']
    file_key = record['s3']['object']['key']
    
    print(f"📥 New file detected: {file_key}")
    
    # Download the file from S3
    response = s3.get_object(Bucket=bucket_name, Key=file_key)
    content = response['Body'].read().decode('utf-8').splitlines()
    
    # Read CSV
    reader = csv.DictReader(content)
    
    # Transform data (add timestamp, uppercase name, etc.)
    transformed_data = []
    for row in reader:
        row['timestamp'] = datetime.utcnow().isoformat()
        if 'name' in row:
            row['name'] = row['name'].upper()
        transformed_data.append(row)
    
    # Write transformed CSV into memory
    output = io.StringIO()
    writer = csv.DictWriter(output, fieldnames=transformed_data[0].keys())
    writer.writeheader()
    writer.writerows(transformed_data)
    
    # Create processed key name
    processed_key = file_key.replace('raw/', 'processed/')
    
    # Upload back to processed folder
    s3.put_object(
        Bucket=bucket_name,
        Key=processed_key,
        Body=output.getvalue().encode('utf-8'),
        ContentType='text/csv'
    )
    
    print(f"✅ File processed and uploaded to: {processed_key}")
    
    return {
        'statusCode': 200,
        'body': json.dumps({'message': 'Processing complete', 'file': processed_key})
    }
```
